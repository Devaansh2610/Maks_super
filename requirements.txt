# --- Core agent / orchestration ---
# No langgraph-supervisor here on purpose: its supervisor node is itself a
# full create_react_agent ReAct loop, so it re-invokes the LLM a 3rd/4th time
# after every handoff (verified by reading its source). No langgraph-swarm
# either — maks/graph/supervisor.py's router delegates via
# Command(graph=Command.PARENT, goto=<specialist>), the same handoff
# primitive swarm's own tools use internally, without the dependency.
# Specialists are wired as real graph nodes (not called from inside a tool's
# coroutine) specifically so LangGraph Studio can render each one's own
# internal nodes as an expandable subgraph. maks/graph/router.py is a small
# embedding-based fast-path router in front of the supervisor (all-minilm via
# Ollama): confident single-intent requests skip straight to a specialist
# with no LLM call at all; anything ambiguous or compound falls back to the
# supervisor below.

# Still needed for OllamaEmbeddings (the router's embedding model) even
